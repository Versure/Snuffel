## Doel

Een lege maar complete basis: Jop kan de app lokaal starten, alle checks draaien, en de werkwijze met branches, hooks, agents en skills staat klaar zodat M2 en verder via `/mijlpaal-uitvoeren` kunnen.

## Opgeleverd

- npm-workspace in de root met `web/` (Angular 22.2, standalone, zoneless, strict, `strictTemplates`, prefix `snf-`).
- ESLint (angular-eslint) met extra regels: OnPush verplicht, signals, geen `any`, nieuwe control flow, toegankelijkheid in templates.
- Prettier in de root, `.editorconfig`, `.gitattributes` (LF), `.nvmrc`.
- Unit-tests met Vitest (`ng test`), e2e met Playwright (mobiel + desktop) en axe; elke e2e-test faalt bij een verzoek naar een ander domein (`web/e2e/fixtures.ts`).
- Privacycheck `npm run privacy` (`tools/check-no-external-urls.mjs`).
- Git-hooks met husky: commit op `main` geweigerd, lint-staged, commitlint, pre-push weigert `main` en draait `npm run verify`.
- `CLAUDE.md`, agents (`planner`, `implementer`, `tester`, `reviewer`), skills (`mijlpaal-uitvoeren`, `pb-collectie-toevoegen`, `spelcomponent-bouwen`, `schema-wijzigen`), Claude-hooks (`guard-git.mjs`, `format-file.mjs`) en permissies in `.claude/settings.json`.
- `README.md`.

## Handmatige check voor Jop

1. `nvm use 24.22.0`, dan `npm install` in de root.
2. `npm start` en open http://localhost:4200: je ziet de kop "Snuffel" en één zin.
3. `npm run verify`: alles groen.
4. `git switch main`, maak een wijziging en probeer `git commit -am "test"`: geweigerd met "Commit on main refused". Daarna `git checkout -- .` en terug naar de branch.

## Afwijkingen

- Angular 22 vereist Node ≥ 22.22.3; de actieve Node op Jops pc was 22.14. Node 24.22.0 is naast de andere versies geïnstalleerd via nvm; de actieve versie is niet omgezet. `.nvmrc` wijst naar 24.22.0 en de pre-push-hook geeft een duidelijke melding bij een te oude Node.
- Om een pull request mogelijk te maken staat er op `main` één lege commit (`chore: initial commit`) als basis. Die moet eenmalig naar GitHub gepusht worden; daarna gaat alles via branches.
- In de tester-agent zijn de Playwright-tools van de plugin opgenomen (`mcp__plugin_playwright_playwright__*`). Is die plugin later niet geïnstalleerd, dan valt de browsercheck terug op de e2e-tests.

## Risico's en open vragen

- Toestemmingen in `.claude/settings.json` staan `git push` naar `feat/*` en `content/*` toe zonder te vragen; de pre-push-hook en `guard-git.mjs` zijn het vangnet. Ander pushen vraagt bevestiging.
